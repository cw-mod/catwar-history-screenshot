# CatWar — Скриншот истории

Скриншот блока «История» на Игровой CatWar с бейджем времени по МСК.

🌐 **Страница установки:** https://cw-mod.github.io/catwar-history-screenshot/

## Возможности

- 📸 **Скриншот всей истории** — захват всего блока, даже того, что за пределами прокрутки
- 👁 **Скриншот видимой части** — только то, что сейчас на экране
- 🕐 **Бейдж времени МСК** — на каждом скриншоте автоматически ставится отметка времени по Москве
- 💾 **Автосохранение в папку** — через File System Access API (Chrome/Edge), с fallback на обычный download
- 🎨 **Корректные цвета** — автоматическая замена неподдерживаемых CSS-функций (`oklch`, `oklab`, `color()`, и т.д.) на безопасные значения
- 🔄 **Автообновление** — скрипт сам обновляется через `@updateURL`/`@downloadURL`

Дополнительный скрипт **«Автопрокрутка истории вниз»** автоматически прокручивает блок «История» в самый низ после обновления страницы и при появлении новых сообщений — но не мешает читать, если вы сами пролистали наверх.

## Использование

В блоке «История» появятся две кнопки:

- **📸 Вся история** — скриншот всей истории (включая скрытую прокруткой часть)
- **👁 Видимое** — скриншот только видимой части

При первом нажатии браузер спросит папку для сохранения скриншотов (Chrome/Edge). Если отказаться — будет обычный download через браузер.

Имя файла: `история_<режим>_<дд.мм.гггг>_<чч-мм-сс>_МСК.png`

## Совместимость

- ✅ Chrome / Edge (рекомендуется — работает автосохранение в папку)
- ✅ Firefox (только обычный download, File System Access API не поддерживается)
- ⚠️ Tampermonkey версии 4.x и выше

## Технические детали

### Скриншот истории (v1.4.0)

Использует [html2canvas](https://html2canvas.hertzen.com/) 1.4.1 для рендеринга DOM в canvas. Перед захватом:

- Временно снимает ограничения `overflow`/`max-height` с блока истории, чтобы захватить скрытое содержимое
- Заменяет кастомные элементы `multi-find-1-extension` на `span` (совместимость с расширением поиска)
- В клоне документа заменяет неподдерживаемые CSS color functions на безопасные значения
- После захвата — восстанавливает все исходные стили

Бейдж МСК рисуется прямо на canvas через `CanvasRenderingContext2D` — это надёжнее, чем добавлять HTML-элемент перед захватом.

### Автопрокрутка (v1.1.0)

Подписывается на `MutationObserver` блока `#history_block`. Перед скроллом проверяет, находится ли пользователь у дна — если он сам пролистал наверх, скрипт его не дёргает. Debounce 80 мс предотвращает лишние срабатывания при пакетных обновлениях DOM.
