# CatWar — Скриншот истории

Скриншот блока «История» на Игровой CatWar с бейджем времени по МСК.

## Установка

1. Установи [Tampermonkey](https://www.tampermonkey.net/)
2. Нажми: **[Установить скрипт](https://raw.githubusercontent.com/cw-mod/catwar-history-screenshot/main/catwar-history-screenshot.user.js)**
3. Подтверди установку
4. Зайди на [catwar.su/cw3](https://catwar.su/cw3/)

## Использование

- **📸 Вся история** — скриншот всей истории
- **👁 Видимое** — скриншот видимой части
